## 📖 项目简介

gstack 是 Y Combinator 总裁兼 CEO Garry Tan 公开的个人 Claude Code 工作流配置。它把 Claude Code 变成一支虚拟工程团队:一个重新思考产品的"CEO"、一个锁定架构的"工程经理"、一个把关品质的"设计师"、一个"发布经理"、一个"文档工程师"和一个"QA",共 23 个各司其职的智能体技能(Agent Skills)。Garry Tan 用这套配置在 60 天内兼职交付了 3 个生产级服务和 40+ 个功能,同时还在全职运营 YC。

## ✨ 主要特性

- 🏢 **虚拟工程团队**:CEO、工程经理、设计师、发布经理、文档工程师、QA 六大角色,23 个专职工具
- ⚡ **惊人交付效率**:作者 2026 年的逻辑代码变更速率约为其 2013 年的 810 倍
- 🔁 **完整工作流**:从产品构思、架构锁定、编码实现到发布管理、质量保障的全流程覆盖
- 🧩 **即插即用**:基于 Claude Code Agent Skills,克隆即可套用到自己的项目
- 📊 **真实战绩背书**:60 天 3 个生产服务、40+ 功能,兼职完成
- 📖 **方法论透明**:附 LOC 争议完整方法论、注意事项与复现脚本

## 🚀 快速开始

完整源代码请访问原项目:https://github.com/garrytan/gstack

1. 克隆原项目到本地:

```bash
git clone https://github.com/garrytan/gstack.git
```

2. 把 `.agents/`(或 `skills/`)目录下的技能复制到你项目的 `.claude/skills/` 目录
3. 按角色启动对应智能体:先让 "CEO" 定义产品,再让 "Eng Manager" 锁定架构
4. 编码任务交给实现智能体,完成后由 "QA" 工具审查
5. 发布阶段交给 "Release Manager" 生成变更说明与发布清单
